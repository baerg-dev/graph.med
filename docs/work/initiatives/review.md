title: Review and feedback
---

From the physician's review: an expert reading the site should be able to say
"this box should be one recommendation, not three" and have it reach the pool as
a reviewable proposal; and "LLM as a judge" — an automated review of extractions
against the source — so far only a heading.

**Scope.** The smallest feedback affordance that produces a reviewable, source-
anchored proposal; a design for automated review that lands as attestations
(spec §8), never as edits to the pool. Granularity itself is settled (memory
`box-granularity-per-sentence`): feedback is about one box, not the rule.

**Out of scope.** Accounts, comments stored on the site, anything that writes to
the pool without a pull request a person merges.
