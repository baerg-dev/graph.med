# Architecture decision records

One file per decision about *how this repository works* — its tooling, its
conventions, its process: `NNNN-<kebab-slug>.md`, numbered in order, never
renumbered, never rewritten (a reversed decision gets a new record that
supersedes the old one). Decisions about the *knowledge model* — what a claim
is, how views are cut, why chapters are provenance — are not ADRs: they are
memories under `.claude/memory/design/`, indexed in
`.claude/rules/conventions/memory.md`. A work package links to whichever
applies.

Format: Context, Decision, Consequences; a Status line (accepted, superseded by
NNNN).
